# Winter Shelter / مشاوير

يحتوي هذا المستودع على واجهة تجريبية لخدمة الطلبات باسم «مشاوير»، ونسخة لعبة بطاقات داخل مجلد `card-game/`.

## تشغيل واجهة مشاوير
افتح `index.html` في متصفح حديث. تحفظ السلة والطلبات محليًا على الجهاز؛ لا يوجد في هذه النسخة تكامل خلفي يرسل الطلبات إلى مندوب فعلي.

## تشغيل لعبة البطاقات
افتح `card-game/index.html` في المتصفح.

## فحص الصياغة
يمكن فحص ملفات JavaScript المستقلة باستخدام `node --check card-game/duel.js` و`node --check card-game/modes.js`. فحص الصياغة لا يثبت سلامة التفاعلات داخل المتصفح.
